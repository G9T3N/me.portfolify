# Modules

- **Project:** Manages work portfolio entries, including metadata like title, slug, summary, used technologies, repo/demo links, and status.
- **Profile:** Defines user identity details such as name, headline, availability, and contact information.
- **Article:** Models written content for a blog/news section, including text content, cover images, tags, and status.
- **Experience:** Tracks professional history, defining companies, roles, employment types, and dates.
- **Skill:** Catalogs professional capabilities divided by proficiency and category.
- **Media:** Models assets (images, videos, documents) used across the platform.
- **SEO:** Represents search engine optimization attributes (titles, descriptions, Open Graph/Twitter card settings).
- **Navigation:** Manages structure for platform menus, including order, visibility, and targets.
- **Social:** Centralizes links to external platform profiles.
- **Settings:** Controls global preferences like theme and analytics.
